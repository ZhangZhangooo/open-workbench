安装与运行

三行命令，
或者双击一个文件

唯一的要求是 Python 3.8 或更新。pip install 一个都不用跑 —— 这是「零第三方依赖」的字面意思。

最快路径 可选依赖 一键脚本 手机访问 遇到问题

最快路径

1

克隆

git clone https://github.com/ZhangZhangooo/open-workbench
cd open-workbench
2

运行

python server.py 8777

Windows 也可以直接双击 start.bat —— 它会先清掉旧实例、再带崩溃自动重启起服务、并自动开浏览器。

3

打开

http://127.0.0.1:8777

就这样。不用装 Ollama 也能先跑起来看界面 —— 模型的事可以晚点再说。

需要准备什么

  • 必需：Python 3.8 或更新。别的什么都不用装。
  • 可选：Ollama（接本机 / 云端模型）、OpenClaw（接 agent 干活）。
  • 可选：WPS（文档读写）、Chrome 或 Edge（内容自动转 PDF）。

可选依赖

Ollama

接本机或 Ollama 云端模型。不装也能用，只是「问一问」会没有模型可问。 官网下载

OpenClaw

接 agent，让它真的去执行 —— 翻文件、跑命令、查系统。npm install -g openclaw。

WPS Office

文档读写集成。仅 Windows。不是必需，缺了只是那个功能用不了。

一键脚本（可选）

系统命令
Windowspowershell -ExecutionPolicy Bypass -File install.ps1
Windows（全自动）powershell -ExecutionPolicy Bypass -File install.ps1 -Yes
macOS / Linuxsudo ./install.sh
macOS / Linux（全自动）sudo ./install.sh --yes

脚本会做什么

  • 装 / 起 Ollama，拉对话模型 gpt-oss:120b-cloud 和看图模型 gemma4:31b-cloud
  • 装 OpenClaw，生成 config.json 指向你本机的 Ollama
  • 默认每一步都把命令打出来等你按回车；加 -Yes 才自动
  • 绝不覆盖你已有的 config.json —— 先备份成 config.json.bak.<时间戳>

手机 / 平板访问

同一 Wi-Fi 直接开

config.json 里 remote.gate 设成 false 就是关闸模式， 同网段的手机平板免密直进。地址在「互传」页面上有现成的一键复制。

装成 App

加到主屏幕即可全屏无地址栏。注意：手机走 http 明文地址时浏览器不给注册 Service Worker， 所以在手机上装不成完整 PWA —— 这是浏览器的安全规矩，不是 bug。

外网访问

家里宽带没公网 IP，需要隧道。工作台的「企业微信」面板里已内置 cloudflared， 点一下「开隧道」就能拿到 https 地址。

遇到问题

  • 端口被占：start.bat 会自动清掉占着 8777 的旧实例。手跑的话先关掉旧窗口。
  • PowerShell 报「文件未经数字签名」：下载的 .ps1 带「来自 Internet」标记。 先跑 Unblock-File install.ps1，或把文件存到本机盘（D:）再执行。
  • macOS 报 command not found: install.sh：必须带 ./。 当前目录不在 $PATH 里。
  • brew 拒绝以 root 运行：这是 brew 的保护机制，脚本内部会自动降回你的用户身份执行。
  • 看不到新功能 / 界面还是旧的：浏览器 Ctrl+F5 强刷。静态资源已设 no-cache， 正常不会缓存，但浏览器有时候很犟。
