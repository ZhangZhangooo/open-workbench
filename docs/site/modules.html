AI 与自动化

OpenClaw

接本机 agent 干活。三个标签：问一问（Ollama 聊天）、干活（OpenClaw 执行）、文档（WPS 全套读写）。

技能库

管理本机的 agent 技能，可在线安装。每个技能是一个带说明的目录，agent 自己决定何时调用。

MCP 接口

把工作台注册成标准 MCP 工具，别的 agent 能正式调用，不用照着提示词猜接口。

邮件

直连 IMAP / SMTP，不依赖任何邮件客户端。收件箱、正文搜索（离线也能搜）、草稿、定时发件箱。

日常

今日

一天的待办。可按项目归属、可勾选、可被 agent 自动补。

任务

比「今日」更长期的任务，有状态流转。

提醒

到点弹桌面通知（页面开着时），可由 agent 自动创建。

日历

日程安排，可由 agent 写入（待确认）。

会议

会议记录与在线会议链接，支持提前提醒。

日志

今天做了什么、按时间倒序。不用手写流水。

知识与资料

资料库

长文档归档，带标签，可全文搜。可由 agent 存入。

笔记

随手记。比资料库轻，给还没整理的东西。

项目

多条线并行，每条记下一步该做什么。agent 可推进。

文件

本机几十万文件的秒搜 + 正文搜索。不是只搜文件名。

系统与工具

系统

真终端（Windows ConPTY）+ 磁盘、端口、进程状态。不是网页里假装的那种 shell。

系统工具

端口占用、清理建议、环境体检。只列不删 —— 破坏性操作一律要你自己确认。

小工具

二维码、单位换算、密码生成等零碎工具，装一起不占地方。

功能清单

全部功能一张表，按域分组，告诉你每项是不是真能用。

设置

AI 接口、OCR 模型、索引范围、连接器、企业微信、局域网、备份、模块管理、语言。

生活

番茄钟

计时 + 统计，一天到底干了多少有效时间。

习惯打卡

连续天数 + 打卡日历。断了会提醒。

剪贴板

本机剪贴板历史，按时间回溯。

房间布置

20 平米怎么摆：布局、设备位、网线走向、充电区，量化出来。

生活

记账 + 生活杂项。超支会顺带提醒。

硬件

打印机

普通打印机自动发现 + 3D 打印机三协议。自动出 PDF、唤起系统打印框、调份数纸张双面。

互传

设备间传文件，原始字节直传不重编码。配额度、过期清理、命中计数。
